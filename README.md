# Atypy account deletion page

`index.html` is the public account deletion request page for the Atypy mobile app.

To publish with GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.

After the Pages deployment finishes, the public URL should be:

https://ishowroom-dev.github.io/atypy-delete-acc/

Check that the URL loads before entering it into Google Play Console. The app must also have a discoverable path to request account deletion.
